The quick version

Open-weight AI models are models whose trained weights you can download and run yourself, rather than only reaching them through a company's app or API. Hugging Face's model hub is the main place people find, compare and download them, and Google's Gemma family is one of the best-known examples from a big lab.

What 'open-weight' meansThe trained weights are downloadable; licenses vary
Where to find themHugging Face model hub
Big-lab exampleGoogle Gemma
Why people use themRun locally, keep data private, fine-tune for a task, lower per-use cost
CatchLicenses differ, and running big models needs serious hardware

How to pick one

  1. Check the license on the model card. Some allow commercial use and some don't.
  2. Check the size. Smaller models run on a laptop; bigger ones need a strong GPU.
  3. Test on your own task before trusting a leaderboard.

Security matters too. This week's PHP2Shell flaws were found by researchers using AI tools, a reminder that AI cuts both ways. More: everything in tech and AI and our explainers.

Quick answers

What is an open-weight AI model?

A model whose trained weights are published for download, so you can run or fine-tune it yourself. Licenses vary.

Where can I download open-source AI models?

The Hugging Face model hub is the main directory. Google publishes its Gemma models through its own developer site too.

Can I use open-weight models commercially?

It depends on each model's license, so read the model card first.
